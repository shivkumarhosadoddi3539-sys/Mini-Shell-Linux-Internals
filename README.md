# Mini-Shell-Linux-Internals
Developed a Linux-based command-line shell in C that implements core functionalities similar to the Bash shell. The project demonstrates Linux system programming concepts, process management, system calls, and inter-process communication.

Key Features:
Executes Linux commands using system calls.
Implemented process creation and management.
Supports command piping.
Handles environment variables.
Uses IPC mechanisms for process communication.
Demonstrates Linux system calls, process management, and file descriptors.
